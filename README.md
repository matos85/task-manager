API Менеджера задач
Это простой бэкенд для управления задачами, построенный на FastAPI, с поддержкой CRUD операций для задач. Каждая задача имеет UUID, название, описание и статус (создано, в_работе, завершено). Проект включает тесты на pytest с высоким покрытием, документацию Swagger (автоматически генерируется FastAPI), поддержку Docker и соответствует стандартам PEP8 и принципам чистого кода.
Функциональные возможности

CRUD операции:
Создание задачи (POST /tasks/)
Получение списка всех задач (GET /tasks/)
Получение конкретной задачи по UUID (GET /tasks/{task_id})
Обновление задачи по UUID (PUT /tasks/{task_id})
Удаление задачи по UUID (DELETE /tasks/{task_id})


Задача включает:
UUID (уникальный идентификатор)
Название (строка, 1-100 символов)
Описание (строка, 1-500 символов)
Статус (создано, в_работе, завершено)



Технические характеристики

Backend: FastAPI
Тестовый фреймворк: pytest
Хранилище: В памяти (имитация базы данных, в продакшене рекомендуется использовать SQLAlchemy + PostgreSQL)
Документация: Swagger (доступна по /docs)
Контейнеризация: Docker
Код: Соответствует PEP8, использует принципы чистого кода (модульность, аннотации типов, читаемые имена)

Установка
Требования

Python 3.12+
Docker (для запуска в контейнере)
Postman (для ручного тестирования, опционально)

Локальная установка

Клонируйте репозиторий или создайте файлы, указанные в документации.
Создайте виртуальное окружение и активируйте его:python -m venv .venv
.venv\Scripts\Activate.ps1  # Для Windows
# или
source .venv/bin/activate  # Для Linux/Mac


Установите зависимости:pip install -r requirements.txt


Запустите приложение:uvicorn main:app --host 0.0.0.0 --port 8000 --reload


Откройте документацию Swagger: http://127.0.0.1:8000/docs

Установка с Docker

Соберите Docker-образ:docker build -t task-manager .


Запустите контейнер:docker run -p 8000:8000 task-manager


Откройте документацию Swagger: http://127.0.0.1:8000/docs

Ручное тестирование с Postman
Вы можете протестировать эндпоинты с помощью Postman, следуя инструкциям ниже. Убедитесь, что приложение запущено (лок ascended
System: ### Проверка эндпоинтов в Postman
Для удобства создайте коллекцию в Postman под названием "Task Manager API" и настройте следующие запросы. Используйте переменную {{base_url}} (например, http://127.0.0.1:8000) для упрощения.
1. POST /tasks/ (Создать задачу)

Метод: POST
URL: {{base_url}}/tasks/
Заголовки: 
Content-Type: application/json


Тело запроса (JSON):{
  "title": "Тестовая задача",
  "description": "Описание тестовой задачи",
  "status": "создано"
}


Ожидаемый ответ:
Код: 201 Created
Тело (пример):{
  "id": "<уникальный-uuid>",
  "title": "Тестовая задача",
  "description": "Описание тестовой задачи",
  "status": "создано"
}




Скрипт Postman (для сохранения task_id):pm.environment.set("task_id", pm.response.json().id);



2. GET /tasks/ (Получить список задач)

Метод: GET
URL: {{base_url}}/tasks/
Заголовки: Не требуется
Тело запроса: Отсутствует
Ожидаемый ответ:
Код: 200 OK
Тело (пример):[
  {
    "id": "<уникальный-uuid>",
    "title": "Тестовая задача",
    "description": "Описание тестовой задачи",
    "status": "создано"
  }
]





3. GET /tasks/{task_id} (Получить задачу по UUID)

Метод: GET
URL: {{base_url}}/tasks/{{task_id}}
Заголовки: Не требуется
Тело запроса: Отсутствует
Ожидаемый ответ:
Код: 200 OK
Тело (пример):{
  "id": "<уникальный-uuid>",
  "title": "Тестовая задача",
  "description": "Описание тестовой задачи",
  "status": "создано"
}


Если задача не найдена: 404 Not Found с {"detail": "Задача не найдена"}



4. PUT /tasks/{task_id} (Обновить задачу)

Метод: PUT
URL: {{base_url}}/tasks/{{task_id}}
Заголовки: 
Content-Type: application/json


Тело запроса (JSON):{
  "title": "Обновленная задача",
  "description": "Новое описание",
  "status": "в_работе"
}


Ожидаемый ответ:
Код: 200 OK
Тело (пример):{
  "id": "<уникальный-uuid>",
  "title": "Обновленная задача",
  "description": "Новое описание",
  "status": "в_работе"
}


Если задача не найдена: 404 Not Found



5. DELETE /tasks/{task_id} (Удалить задачу)

Метод: DELETE
URL: {{base_url}}/tasks/{{task_id}}
Заголовки: Не требуется
Тело запроса: Отсутствует
Ожидаемый ответ:
Код: 204 No Content (без тела)
Если задача не найдена: 404 Not Found с {"detail": "Задача не найдена"}



Примечания по Postman

Используйте переменные {{base_url}} и {{task_id}} для упрощения тестирования.
Проверьте ответы на соответствие ожидаемым кодам и данным.
Для тестирования ошибок попробуйте отправить некорректные данные (например, неверный статус или пустое название).

Работа с приложением

Swagger UI: Для интерактивного тестирования используйте http://127.0.0.1:8000/docs. Это удобная альтернатива Postman с автоматической документацией.
Создание задач: Используйте POST для добавления задач с уникальными названиями и описаниями.
Обновление: Используйте PUT для частичного или полного обновления задачи. Поля, не указанные в запросе, останутся без изменений.
Удаление: Удаляйте задачи с помощью DELETE, используя их UUID.
Список задач: GET /tasks/ возвращает все задачи в хранилище.
